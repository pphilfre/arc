# Arc

A fast, native navigation app for iPhone, built with SwiftUI and Mapbox.

Arc is designed around a simple idea: navigation should feel like it belongs on iOS. It combines Mapbox's mapping and navigation platform with a minimal, map-first interface built using native SwiftUI and Liquid Glass.

## Features

- Native SwiftUI interface
- Mapbox-powered maps and navigation
- 2D and 3D map views
- Place and category search
- Driving and walking routes
- Multi-stop journey planning
- Live traffic information
- Turn-by-turn navigation
- Lane and roundabout guidance
- Current speed and speed limit display
- Live Activities during navigation
- Haptic feedback
- Local search and journey history
- Saved places
- Light and dark appearance
- Designed for iOS 26 and Liquid Glass

## Design

Arc is designed to feel at home on iPhone rather than like a web interface inside an app.

The map remains the focus, with controls appearing contextually when they're needed. Native materials, typography, animations and haptics are used throughout to keep interactions quick and familiar.

## Built With

- **Swift**
- **SwiftUI**
- **Mapbox Maps**
- **Mapbox Navigation**
- **Mapbox Search**
- **Core Location**
- **SwiftData**
- **ActivityKit**
- **Core Haptics**
- **AVFoundation**

Arc does not require an account or backend. Settings, saved places, recent searches and journey history are stored locally on the device.

## Requirements

- iOS 26.0+
- Xcode 26+
- Mapbox access token

## Getting Started

Clone the repository:

```bash
git clone https://github.com/pphilfre/arc.git
cd arc
```

Add your Mapbox access token to the project's configuration, then open the project in Xcode and build for an iPhone or simulator.

## Status

Arc is currently in development. Features and interface elements may change as the app develops.
